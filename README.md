# Fewdo legacy upgrade bridge

Fewdo 的正式发布仓库已迁移到 [fewdo-release](https://github.com/caijinyc/fewdo-release)。原仓库的全部历史保留在新地址。

本仓库仅提供 **v0.2.99** 兼容升级版。旧客户端可先升级到该版本，再检查更新获取最新版本。此兼容版长期保留；未来版本只发布到新仓库。

The original repository, including its release history, is now **fewdo-release**. This compatibility repository retains **v0.2.99** so older clients can upgrade to the new update source. Install the bridge version, then check for updates again. Future releases are published only in the new repository.

旧版设置中的 Skill 安装路径保留兼容；最新 Skill 请使用 [fewdo-analysis](https://github.com/caijinyc/fewdo-release/tree/main/skills/fewdo-analysis)。
